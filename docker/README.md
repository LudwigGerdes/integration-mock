# Docker pair — n8n + mock

`integration-mock up` builds and starts two containers:

| Service | Port | Notes |
|---|---|---|
| `mock` | 8080 (proxy), 8081 (admin) | admin binds `0.0.0.0` inside the compose network only |
| `n8n`  | 5690 → 5678 | proxied through `mock`, trusts its CA; move it with `INTEGRATION_MOCK_N8N_PORT` |

The CA is generated by the mock daemon on first boot into the shared `mockdata`
volume at `/data/ca.pem`; n8n mounts that volume read-only and trusts the file
via `NODE_EXTRA_CA_CERTS`. A healthcheck on `mock` gates n8n's start on the CA
file existing, so n8n never boots pointed at a certificate that is not there yet.

```bash
integration-mock up          # build + start, writes ~/.integration-mock/proxy.json (ports + the pair's admin token)
integration-mock status      # mode / packs / snapshot / faults
integration-mock down        # stop and remove proxy.json
```

### Build notes

**pnpm is pinned.** The root `package.json` carries
`"packageManager": "pnpm@10.22.0"` and the Dockerfile copies the manifests
before `corepack prepare --activate`. Without the pin, `corepack` asks the npm
registry what "latest" is at build time — a network round-trip for a question it
should not be asking, and a different pnpm on different days, which defeats the
`--frozen-lockfile` on the next line.

**Docker daemons behind a proxy.** buildkit does not inherit the daemon's proxy
settings. If `docker info` reports an HTTP/HTTPS proxy and the build fails with
`ETIMEDOUT` reaching `registry.npmjs.org` (while `docker run` and image pulls
work fine), either add a `proxies` block to `~/.docker/config.json` or pass it
per build:

```bash
docker compose -f docker/docker-compose.yml build \
  --build-arg HTTP_PROXY=http://http.docker.internal:3128 \
  --build-arg HTTPS_PROXY=http://http.docker.internal:3128 \
  --build-arg NO_PROXY=hubproxy.docker.internal,localhost,127.0.0.1
```

**Host port clashes.** The n8n host port is `${INTEGRATION_MOCK_N8N_PORT:-5690}`. Set it
when 5690 is taken: `INTEGRATION_MOCK_N8N_PORT=5691 integration-mock up`.
